# Panství

Lokální hratelný prototyp karetní hry o budování panství.

Otevřete `index.html` v moderním prohlížeči. Prototyp obsahuje první balíček deseti karet, produkci, aktivní efekty, dobírání, vylepšování, větvený vývoj, čtyřstavové ilustrace, konec tahu a objevování dvou karet na konci kola.

Aktualizované rozhraní používá emoji pro suroviny, dvanáct pevných pozic ve dvou řadách, přesouvání karet tažením, viditelný dobírací i odhazovací balíček a animované rozdávání a odhazování. Produkce kartu pouze vyčerpá a ponechá ji na stole do konce tahu.

Hodnoty a pořadí v tomto raném prototypu sledují strukturu úvodní ekonomiky referenční hry. Texty, názvy, rozhraní a ilustrace jsou původní.
